# Table

Semantic table parts for reference data.

Source: `src/components/ui/table.jsx`.

- Parts: `Table`, `TableHeader`, `TableBody`, `TableFooter`, `TableRow`, `TableHead`, `TableCell`, `TableCaption`.
- Use for equivalence tables, dose bands and lab ranges. Right-align numbers; keep units in the header or the cell, never implied.
- The table scrolls horizontally inside its own wrapper on narrow screens.
